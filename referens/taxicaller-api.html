TaxiCaller API v1

Alla endpoints i TaxiCallers officiella API-dokumentation, samlade på en sida. Sök på sökväg eller beskrivning, filtrera på metod och kopiera sökvägen direkt. Källa: app.taxicaller.net/documentation/api.

https://api.taxicaller.net https://api-rc.taxicaller.net (test) Auth: Bearer JWT

Autentisering

Hämta en JWT med er API-nyckel och skicka den som Authorization: Bearer <token> i alla andra anrop. sub=* ger token för alla subjects.

curl "https://api.taxicaller.net/api/v1/jwt/for-key?key=API_NYCKEL&sub=*"

curl -H "Authorization: Bearer $JWT" \
  "https://api.taxicaller.net/api/v1/company/COMPANY_ID/vehicle/list"
Inga endpoints matchar sökningen.
